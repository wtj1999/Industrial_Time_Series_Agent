# 公共离线数据

将需要向所有已登录用户共享的 CSV、XLSX 或 Parquet 文件直接放在此目录。

- 页面入口：我的数据 → 离线数据源 → 公共数据。
- 所有用户看到同一份文件列表，支持前 50 行预览；私有上传仍保存在原用户目录中。
- 文件添加、替换或移除后，点击页面“刷新”即可，无需重新构建前端。文件建议先写入其他位置，再完整移入目录。
- 不扫描子目录，不展示隐藏文件、符号链接和其他类型文件；此说明文件不会展示。
- 公共数据由服务器文件系统维护，页面不提供上传、删除或修改公共文件的接口。
- Docker Compose 已挂载整个 `agent_app` 目录，对应服务器目录为 `/data/ts_agent/agent_app/public_datasets/`（以实际项目路径为准），容器目录为 `/app/agent_app/public_datasets/`。
- 请单独备份和同步此目录中的实际数据文件。
