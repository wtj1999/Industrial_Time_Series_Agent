# 在线表卡片指标

“我的数据 → 在线数据源 → 工厂数据表”的每张卡片右上方展示三个指标。

- 完整率：最近100条记录中，非空单元格数 / 全部单元格数。检查所有列；NULL、空字符串、纯空格及非有限数值算缺失，0和False不算缺失。
- 重复率：整列数值完全相同的数值列数 / 数值列总数。按数据库字段类型识别数值列（整数、浮点、decimal等），不计算字符或日期列，即使字符列存放数字也不参与。每个数值列在实际样本的全部记录中均为同一个有效值记1，否则记0；含NULL或非有限数值的列不记1，全为0的列记1。例如10个数值列中3列保持同值，显示30%。不足100条按实际样本判断；无数值列或空表显示“—”。这反映数值列恒定的比例，不再计算整行重复。
- 时效：样本中最新insert_time距检测时间的间隔，前端每分钟更新相对时间。无时区的工厂时间按北京时间解释；悬停展示完整北京时间。未来时间显示“时间超前”，不自动当作刚更新。

接口 `GET /api/online-sources/{source_id}/tables/{table_name}/metrics`：先校验配置数据源、表元数据及insert_time，再执行 `SELECT * ... ORDER BY insert_time DESC LIMIT 100`。只返回指标、样本量及时间信息，不返回原始记录或凭据；不足100条按实际行数计算，空表的完整率/重复率为空，显示“—”和“暂无数据”。指标与预览筛选相互独立。

卡片进入可见区域附近后才请求指标，客户端最多并发4个请求。指标失败不阻止点击卡片预览；切换工厂或离开页面会取消请求，页面“刷新”重新计算指标。

验证：

```sh
python -m pytest agent_app/utils/test_online_data_sources.py -q
cd frontend
npm run test:online-metrics
npm run build
```
