# 对话工作台布局预览

已将第三版「信号切片」Logo 整理为可缩放 SVG，接入前端品牌组件。

- 桌面：Logo 和中英文名称固定在左侧栏顶部。
- 对话区顶部第一行显示工作台名称、当前任务和阶段；第二行显示 CSV 画像和规格确认状态。刷新与重置按钮位于右侧。
- 去除侧栏重复的阶段、任务信息；保留会话编号、轮次、结果数和更新时间。
- 我的数据、我的模型、我的智能体及 BI 业务智能体页面直接移除整块通用对话顶部状态栏，不保留重复标题或空白占位；窄屏仅保留独立品牌入口。
- 左侧栏顶部的 Logo 与中英文名称作为一个整体水平居中。
- 阶段显示兼容大小写，execution / Execution / EXECUTION 均显示「任务执行」。

## 验证

生产构建通过。使用本地浏览器和隔离模拟 API 响应验证了 1440、1024、768、390、320 像素宽度，检查状态显示、刷新与重置、资源导航、返回对话、新建会话、SVG 加载和横向溢出。模拟响应仅在测试浏览器中生效，未访问真实账户或写入后端数据。

desktop.png、mobile.png 和 empty.png 是通用对话截图；data.png、models.png、agents.png、bi.png 展示移除顶部状态栏后的资源页和 BI 页面。全部为实际前端渲染截图，使用隔离模拟会话数据。浏览器检查同时确认品牌居中、资源页主内容从顶部开始、BI 页面无通用流程状态栏，以及窄屏仍有品牌入口。checks.json 保存检查结果。
